# 0\. 项目目标

本项目目标是： 基于一个普通白色大容量陶瓷杯，从 0 到 1 建立一个完整的年轻生活方式品牌视觉系统。

品牌名称：

-   英文名：CupBuddy
-   中文名：好搭杯
-   IP 名称：搭搭鸟 / Buddy Bird

品牌核心表达：

好大一杯，好搭一天。 每天搭你，每天陪你。

品牌定位：

一个面向年轻上班族、学习人群、居家办公人群的 700ml 大容量桌面陪伴杯品牌。 它不是单纯卖杯子，而是卖一种“桌面搭子”“情绪陪伴”“生活方式感”。

核心产品：

-   白色陶瓷大容量办公杯
-   容量约 700ml
-   风格简洁、温润、低调
-   适合咖啡、茶、水、牛奶等多种饮品
-   适合办公室、学习桌、居家办公、送礼场景

-   Cup：杯子
-   Buddy：搭子、伙伴、陪伴者

好搭杯

-   好搭：咖啡、茶、水、桌面场景都好搭

# 5\. IP 形象设计：搭搭鸟 Buddy Bird

## 5.1 IP 设定

IP 名称：

-   中文名：搭搭鸟
-   英文名：Buddy Bird

角色定位：

CupBuddy 的桌面陪伴官。 一只圆润、稳定、安静、温暖的小鸟，像真实桌面公仔一样陪在用户身边。

性格关键词：

温柔 稳定 安静 可靠 有点害羞 不打扰 默默支持 情绪稳定 小小治愈

口头禅：

每天搭你，每天陪你。

## 5.2 IP 标准造型

搭搭鸟必须保持以下特征：

奶油白圆润身体 胖乎乎、低重心 头身一体 顶部两撮小羽冠 深咖啡色小眼睛 小橙黄色鸟嘴 柔和腮红 短小圆润翅膀 小黄脚 搭搭蓝围巾 围巾末端有白色 C 标识

## 5.3 禁止变形规则

禁止：

变瘦 变长 变成人形 变真实鸟类 眼睛变大 嘴巴变大 去掉围巾 去掉小羽冠 变成毛绒动物 变成机器人 变成过度卡通 变成低幼玩具

# 6\. IP 图片生成提示词

## 6.1 搭搭鸟标准形象提示词

Create a premium 3D mascot character for CupBuddy, named Buddy Bird / 搭搭鸟. The character is a cute round cream-white bird mascot with a chubby low-center body, tiny feather tuft on top, small dark coffee-colored eyes, subtle curved eyebrows, a small orange-yellow beak, soft blush cheeks, tiny yellow feet, and a buddy-blue scarf tied at the front with a small white “C” mark on the scarf. Keep the silhouette very round, stable, and compact. Do not make it slim, human-like, furry, realistic bird-like, robotic, or overly cartoonish.
