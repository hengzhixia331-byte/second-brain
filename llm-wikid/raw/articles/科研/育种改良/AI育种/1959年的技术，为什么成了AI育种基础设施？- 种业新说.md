> AI育种时代，最被低估的不是AI，而是1959年的DH。CRISPR在进化，全基因组选择（GS）在进化，AI模型在进化DH在变得更底层。
> 
> 当CRISPR、GS、AI模型成为育种家街头巷尾谈论话题时，一个更底层的事实正在发生： DH不是被替代，而是被加码投资。
> 
> 拜耳、科迪华、先正达、利马格兰、科沃施等巨头的研发结构都在释
> 
> 放同一个信号：技术越先进，DH越关键。
> 
> 你可能想为什么一个上世纪技术，没有被淘汰，反而变成AI时代基础设施？
> 
> 答案可能只有一句话：DH不是技术，变成育种系统可计算性的底座。

****第一层误解：DH只是“加速工具”****

DH的育种定位非常简单：把6-8代自交，压缩到1代完成。传统路径：F1 → F2 → F3 → F4 → F5 → F6 → F7（稳定系）。DH路径：F1 → 单倍体诱导 → 染色体加倍 → 纯合系。

简单一句概括：DH不是优化育种流程，而是压缩育种时间维度。目前看这个判断只对了一半。因为它忽略了DH真正的价值跃迁发生在第二阶段。

AI在优化“答案”，DH在定义“答案是否存在”，全基因组选择（GS）如国内液相芯片开创者博瑞迪开发一系列GS育种芯片出现之后，育种逻辑发生根本变化。

![[llm-wikid/raw/assets/images/d4b73dc9b6c3169a10b2f08829c690b5_MD5.png]]

△图1 玉米20K液相芯片核心位点注释情况\*核心SNP标记中，有30.55%位于外显子（exonic）区域。©博瑞迪

**第二层跃迁：DH变成“AI训练数据工厂”**

全基因组选择（GS）出现之后，育种逻辑发生根本变化：从经验选种 → 模型预测；从个体判断 → 群体建模。

GS的前提只有一个：稳定数据，GS不缺算法，缺的是稳定输入。没有稳定数据，就没有模型精度。而传统杂合材料的问题是：基因表达不稳定；G×E年际间波动极大；重复试验不可控。模型“学不准”，后面预测准确率更不用提了。

DH提供三件事：纯合，固定，可重复。AI育种时代，DH不是被AI替代，而是成为AI的前置条件。

![[llm-wikid/raw/assets/images/4065b2385e7c9893781a3f644ddecc5d_MD5.png]]

△图2 未来试验田。

**第三层升级：DH进入“基因编辑落地层”**

基因编辑的真实瓶颈，从来不是编辑本身，而是如何把编辑结果快速“固定成品系”。现实路径是：编辑成功 → 回交 → 自交 → 纯化 → 稳定 → 测试，周期仍然极长。DH介入后路径被重写：编辑 → 单倍体诱导 → DH固定 → 直接纯系，结果是：5-6代 → 2-3代，不确定性大幅下降，工程化育种成立。

基因编辑不缺效率，缺确定性，DH让编辑结果，第一次变成“可固化品系”。

![[llm-wikid/raw/assets/images/9c19d7a5127f3ad55d4468afd13c3342_MD5.png]]

△图3 作物育种中 HI-Edit 或 IMGE 的过程和原理。©崔晓峰等

****第四层变化：**DH重写杂交种开发逻辑**

传统育种模式：群体构建 → 多代自交 → 自交系 → 测配 → 筛选，新模式：群体 → DH → 测配 → 快速筛选。搜索空间被指数级放大。过去一年测试几百组合，现在加上GS如国内博瑞迪GS育种芯片等，可能是几千，甚至上万组合。

![[llm-wikid/raw/assets/images/cd087561661eb512ef62e56c1e38a955_MD5.png]]

△图4 玉米20K液相芯片核心SNP位点染色体分布图

\*标尺释义：在基因组上每个滑动窗口（窗口步长为50 Kb）内SNP的个数©博瑞迪

过去是经验驱动选育，现在是高维空间搜索。育种不再是筛选，是算力科学。

育种的本质，是在不断变化的约束条件下，用有限遗传资源逼近动态最优解。

**DH决定育种系统能否闭环**

DH的终极意义，不是加速，也不是固定，它让整个育种系统第一次具备“计算一致性”。

AI负责“选择”，GS负责“概率”，只有DH负责一件最底层的事：把所有结果变成“可复现的现实”。假如没有DH：数据不可控；模型不稳定；编辑无法固化。

DH把育种从概率系统，变成工程系统。

**被低估的从来不是技术**

一个清晰的产业结构正在形成：AI决定“选什么”，基因编辑决定“能改什么”，GS决定“概率有多大”，DH决定“现实能不能成立”。

未来种业竞争，不是AI竞争，是DH基础设施竞争。

AI定义选择空间，DH定义现实边界。

不是AI决定育种上限，是DH决定AI的上限。
