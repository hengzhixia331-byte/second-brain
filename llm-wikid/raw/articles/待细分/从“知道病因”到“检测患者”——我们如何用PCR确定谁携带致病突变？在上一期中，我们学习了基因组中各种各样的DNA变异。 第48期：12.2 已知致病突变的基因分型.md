## 从“知道病因”到“检测患者”——我们如何用PCR确定谁携带致病突变？

在上一期中，我们学习了基因组中各种各样的DNA变异。现在，我们面临一个更实际的问题：**如果我们已经知道某种疾病是由特定基因突变引起的（如镰刀形贫血的HbβS突变），如何快速、准确地检测一个人是否携带该突变？**

一个根本问题随之而来：**如何在30亿个碱基的基因组中，找到并分析哪一个关键的致病位点？**

本期将回答：**PCR如何像“分子复印机”一样特异性扩增目标DNA区域；如何通过测序或电泳确定基因型；如何在胎儿或胚胎中进行产前诊断。**

> 📌 **核心类比**：PCR是一个“分子复印机”——你给它在基因组中指定一个“起始地址”和“结束地址”，它就能把这段DNA复制出数百万份，让你有足够的材料去分析。
> 
> -   **引物（Primers）**：像两个“地址标签”，贴在目标区域的两端
>     
> -   **DNA聚合酶**：复印机的“打印头”
>     
> -   **热循环**：复印机反复开关的“加热/冷却”过程
>     
> -   **测序**：读出复印的内容，看看有没有“错字”（突变）
>     
> -   **电泳**：测量复印出来的“长度”（检测SSR重复数变化）
>

## 一、PCR：分子世界的“复印机”

> ![](https://relay-1.bijitongbu.site/p/a817624a505daba36d5cdec93c3076cc.png)
> 
> **PCR概述**
> 
> **图片内容**：展示PCR的基本原理：
> 
> -   **基因组DNA**：两条链（蓝色和红色），包含目标区域
>     
> -   **引物1和引物2**：两个短DNA片段，**5′→3′方向指向目标区域内部**
>     
> -   **～30轮PCR循环** → 目标区域被**指数级扩增** → 得到**数十亿个拷贝**（PCR产物）
>     
> 
> **讲解要点**：

### 1.1 PCR的核心：两条引物定义目标区域

| 引物 | 位置 | 5′→3′方向 |
| --- | --- | --- |
| **正向引物** | 目标区域**左侧** | **向右**延伸（覆盖目标区域） |
| **反向引物** | 目标区域**右侧** | **向左**延伸（覆盖目标区域） |

> 📌 **关键要求**：两条引物的5′→3′方向必须**指向对方**（即指向目标区域内部）。这是PCR扩增的“几何学”基础。

### 1.2 PCR的三个温度步骤

> ![](https://relay-1.bijitongbu.site/p/4facff7fc4b3b0444c41ae168cfe31a4.png)
> 
> **PCR如何扩增目标序列**
> 
> **图片内容**：详细展示PCR循环的三个温度步骤，以及每次循环后DNA分子数的倍增：
> 
> -   **第1轮**：1个分子 → 2个分子
>     
> -   **第2轮**：2个分子 → 4个分子
>     
> -   **第3轮**：4个分子 → 8个分子
>     
> -   ……
>     
> -   **第n轮**：2ⁿ个分子
>     
> 
> **讲解要点**：

| 步骤 | 温度 | 时间 | 发生的事件 |
| --- | --- | --- | --- |
| **1\. 变性（Denaturation）** | **～94-98°C** | 30秒-1分钟 | DNA双链**解链**成两条单链模板 |
| **2\. 退火（Annealing）** | **～50-65°C** | 30秒-1分钟 | 引物与模板上的**互补序列**结合 |
| **3\. 延伸（Extension）** | **～72°C** | 1-2分钟/千碱基 | **耐热DNA聚合酶**（Taq聚合酶）从引物3′端**延伸**新链 |

### 1.3 Taq聚合酶：来自“热水”的超级酶

| 特征 | 说明 |
| --- | --- |
| **来源** | **Thermus aquaticus**——生活在**黄石国家公园热泉**中的细菌 |
| **关键性质** | 在**～95°C仍保持活性**（普通DNA聚合酶在此温度会失活） |
| **为什么重要** | PCR需要反复加热到95°C变性DNA，Taq聚合酶**不会因加热失活** |

> 📌 **指数扩增的威力**：
> 
> -   **22轮循环** → 2²² ≈ **400万倍**扩增
>     
> -   **32轮循环** → 2³² ≈ **40亿倍**扩增
>     
> -   从**单分子**可扩增到**可测序检测的量**！
>

## 二、SNP基因分型：在“错字”处找差异

> ![](https://relay-1.bijitongbu.site/p/0b1e3188d851db96bdbea66e2da834be.png)
> 
> **通过测序PCR产物检测SNP**
> 
> **图片内容**：
> 
> -   **(a) PCR扩增Hbβ基因**：引物位于突变位点**两侧**（不管基因型如何都能扩增）
>     
> -   **(b) 三种基因型的测序结果**：
>     
> 
> -   **Hbβᴬ/Hbβᴬ（正常纯合子）**：在突变位点只有**A峰**（GAG密码子）
>     
> -   **Hbβˢ/Hbβˢ（镰刀形贫血纯合子）**：在突变位点只有**T峰**（GTG密码子）
>     
> -   **Hbβᴬ/Hbβˢ（杂合子/携带者）**：在突变位点同时有**A峰和T峰**（叠加的“双峰”）
>     
> 
> **讲解要点**：

### 2.1 检测SNP的策略

| 步骤 | 操作 | 说明 |
| --- | --- | --- |
| **1\. PCR扩增** | 使用突变位点**两侧**的引物 | 无论哪种等位基因都能扩增（引物不跨越突变位点） |
| **2\. 测序反应** | 用其中一个PCR引物进行**Sanger测序** | 确定突变位点的具体碱基 |
| **3\. 读取结果** | 检查测序峰图 | **单个峰**→纯合子；**双峰**→杂合子 |

### 2.2 为什么杂合子显示“双峰”？

| 因素 | 说明 |
| --- | --- |
| **两个等位基因同时存在** | 基因组DNA中有一条染色体带A，另一条带T |
| **PCR同时扩增两者** | 两种模板都被扩增，产物中一半是A，一半是T |
| **测序同时读取两者** | Sanger测序从混合模板中读取信号→**两个峰叠加** |
| **结果** | 在突变位点出现**两个相等高度的峰**（A和T）→杂合子 |

> 📌 **临床应用**：
> 
> -   **纯合正常（AA）**：两个A峰 → 完全正常
>     
> -   **纯合突变（SS）**：两个T峰 → 镰刀形贫血患者
>     
> -   **杂合子（AS）**：A峰+T峰 → 携带者（有抗疟疾优势）
>

## 三、SSR/STR基因分型：通过“长度”判断

> ![](https://relay-1.bijitongbu.site/p/794b430c4ac2efd728d400dda29d02bb.png)
> 
> **通过PCR产物电泳进行SSR基因分型**
> 
> **图片内容**：
> 
> -   **(a) SSR位点结构**：两个等位基因，重复次数不同（CA重复）
>     
> -   **(b) PCR扩增**：引物位于重复区域的**两侧**
>     
> -   **(c) 凝胶电泳**：不同等位基因的PCR产物大小不同→在凝胶上形成**不同的条带**
>     
> -   **(d) 群体的基因型多样性**：显示3个等位基因和6种可能的基因型组合
>     
> 
> **讲解要点**：

### 3.1 SSR基因分型的原理

| 特征 | 说明 |
| --- | --- |
| **待检测位点** | **SSR（简单序列重复）**：如CA重复、CAG重复等 |
| **等位基因差异** | **重复次数的不同**（如15次 vs 18次） |
| **PCR扩增** | 引物在**重复区域两侧**，扩增整个SSR位点 |
| **检测方法** | 通过**凝胶电泳**（或毛细管电泳）**测量产物大小** |

> 📌 **不同等位基因的区分**：
> 
> -   **15个重复**的等位基因 → PCR产物**较短**
>     
> -   **18个重复**的等位基因 → PCR产物**较长**
>     
> -   两者在凝胶上**迁移速度不同**，形成两条带
>     

### 3.2 亨廷顿病（HD）的SSR检测

> ![](https://relay-1.bijitongbu.site/p/e84433bedea309373c377e11c40517e3.png)
> 
> **三核苷酸重复SSR的扩增导致亨廷顿病**
> 
> **图片内容**：
> 
> -   **(a) HD基因中的CAG重复**：在编码区开头，编码多聚谷氨酰胺（polyQ）
>     
> -   **(b) 不同重复数的等位基因**：
>     
> 
> -   **20个重复**：正常（灰色）
>     
> -   **30个重复**：正常（较长的灰色）
>     
> -   **50个重复**：晚发型疾病（橙色）
>     
> -   **100个重复**：早发型疾病（红色）
>     

**亨廷顿病的基因型—表型关系**：

| CAG重复次数 | 分类 | 表型 |
| --- | --- | --- |
| **≤35** | 正常 | **无症状** |
| **36-39** | 不完全外显 | 部分人**晚年发病** |
| **≥40** | 完全外显 | **必然发病** |
| **≥50** | 高度外显 | **发病年龄更早** |

> 📌 **“重复次数越多，发病越早”**：
> 
> -   40个重复：约**50-60岁**发病
>     
> -   50个重复：约**40-50岁**发病
>     
> -   60个重复：约**30-40岁**发病
>     
> -   > 70个重复：可在**青少年期**发病
>

## 四、产前诊断：在出生前知道“答案”

> ![](https://relay-1.bijitongbu.site/p/38abc74536fb51780549d5a31af685f4.png)
> 
> **植入前胚胎诊断（PGD）**
> 
> **图片内容**：从**8细胞期胚胎**中取出**1个细胞**进行基因检测：
> 
> -   步骤1：从卵巢**取卵**（激素刺激）
>     
> -   步骤2：体外受精（IVF）
>     
> -   步骤3：胚胎发育到**6-10细胞期**
>     
> -   步骤4：用微针**取1个细胞** → **PCR扩增** → **基因分型**
>     
> -   步骤5：选择**健康胚胎**植入子宫
>     

### 4.1 两种产前诊断方法

| 方法 | 时机 | 材料 | 风险 |
| --- | --- | --- | --- |
| **羊膜穿刺** | 孕15-20周 | 羊水中的胎儿细胞 | ～1/200流产风险 |
| **绒毛膜取样（CVS）** | 孕10-13周 | 胎盘绒毛组织 | ～1/100流产风险 |
| **植入前遗传学诊断（PGD）** | **胚胎期（8细胞）** | **一个细胞** | **无**（胚胎继续发育） |

### 4.2 PGD的操作流程

| 步骤 | 操作 | 目的 |
| --- | --- | --- |
| **1\. 促排卵** | 注射激素→一次**多个卵泡**成熟 | 提高成功率 |
| **2\. 取卵** | 超声引导下从卵巢**取卵** | 体外受精 |
| **3\. IVF** | 与伴侣**精子**混合体外受精 | 形成多个胚胎 |
| **4\. 培养** | 培养至**6-10细胞期**（第3天） | 胚胎分裂但不分化 |
| **5\. 活检** | 用微针**取1个细胞** | 遗传物质不受损（胚胎可继续发育） |
| **6\. PCR扩增** | **单细胞PCR**扩增目标位点 | 挑战：从～6pg DNA扩增 |
| **7\. 基因分型** | 测序/电泳 | 确定胚胎**基因型** |
| **8\. 植入** | 选择2-3个**正常胚胎**植入 | 提高着床成功率 |

### 4.3 单细胞PCR的挑战

| 挑战 | 说明 | 解决方案 |
| --- | --- | --- |
| **DNA量极少** | 一个细胞仅～**6pg**DNA | 需要高度**优化的PCR** |
| **等位基因丢失** | 某条染色体可能不被扩增 | 使用**多个标记**位点 |
| **污染风险** | 外来DNA污染 | 严格的无菌操作 |
| **胚胎镶嵌** | 早期胚胎可能有混合细胞 | 检测**多个细胞** |

## 五、核心概念速查表

| 概念 | 定义 | 关键特点 |
| --- | --- | --- |
| **PCR（聚合酶链式反应）** | 体外DNA扩增技术 | 由两条引物定义目标区域，**指数扩增** |
| **Taq聚合酶** | 来自热泉细菌的耐热DNA聚合酶 | 在**～95°C仍具活性** |
| **引物（Primer）** | 短单链DNA，定义扩增边界 | 两条引物5′→3′方向**指向彼此** |
| **SNP基因分型** | 通过测序检测单碱基变异 | 杂合子显示**双峰** |
| **SSR基因分型** | 通过电泳检测重复次数变异 | 不同长度→**不同条带** |
| **亨廷顿病** | CAG三核苷酸重复扩增 | ≥40重复→**必然发病** |
| **产前诊断** | 出生前检测胎儿基因型 | 绒毛膜取样/羊膜穿刺/PGD |
| **PGD** | 植入前遗传学诊断 | 从**8细胞胚胎取1个细胞** |
